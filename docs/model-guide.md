# 按模块理解公式与代码

## 1. 被测电机：电压如何产生电流、磁场和转矩

令二维向量 `i=[iα,iβ]`、`ψr=[ψrα,ψrβ]`，90°旋转算子 `G[a,b]=[-b,a]`。全部使用 SI 单位，p 为极对数。

```text
Lσ = Ls − Lm²/Lr
ψ̇r = (Rr/Lr)(Lm i − ψr) + pωm Gψr
i̇ = [u − Rs i − (Lm/Lr)ψ̇r] / Lσ
Te = (3/2)p(Lm/Lr)(ψrα iβ − ψrβ iα)
ω̇m = (Te − TL − Bωm)/J
```

磁链路径依次是：电流乘 Lm → 减去现有磁链 → 乘 Rr/Lr → 加上旋转耦合项 → 积分。电流路径是：端电压减去电阻压降，再减去磁链变化产生的电压 → 除以漏感 → 积分。机械路径是：电磁转矩减去负载与摩擦 → 除以惯量 → 积分。

积分块在模块图中表示连续物理关系；程序按所选步长进行 RK4 数值积分，不是每个图形块独立运行的通用求解器。

当前教学参数（未绑定实机）：

| 参数 | 数值 | 意义 |
|---|---|---|
| Rs | 1.4 Ω | 定子电阻 |
| Rr | 初始1 Ω，最终1.3 Ω | 转子电阻的实验工况 |
| Lm | 0.17 H | 励磁电感 |
| Ls、Lr | 各0.18 H | 定、转子总自感 |
| p | 2 | 极对数 |
| J | 0.04 kg·m² | 总等效转动惯量 |
| B | 0.002 N·m·s/rad | 黏性摩擦系数 |

这些电感满足 Ls Lr > Lm²，确保漏感为正。替换模型参数时需要保持物理可行性并重新整定控制器。

## 2. 为什么电阻变化会破坏定向

转子磁链定向要求 ψrq=0。在定向坐标系中：

```text
ψ̇rq = −(Rr/Lr)ψrq + (Rr Lm/Lr)iq − ωsl ψrd
```

保持 ψrq=0，得到 `ωsl=(Rr Lm/Lr)iq/ψr`。控制器使用估计或标称电阻 R̂r，计算的滑差可能偏离。同步电角速度为 `ωe=pωm+ωsl`，积分得到 Park 变换的角度。

磁链相对控制坐标的夹角为 δ 时，转矩变成：

```text
Te = (3/2)p(Lm/Lr)ψr(iq cosδ − id sinδ)
```

因此励磁电流也开始影响转矩。观察真实磁链 q 分量和偏角，比只看速度更能解释失配。真实磁链只供仿真评价。

## 3. 三个反馈环

速度误差使用 rad/s：`eω=ω*−ω测量`。速度 PI 输出 q 轴电流指令。d 轴电流指令负责励磁。两条电流 PI 根据各自误差输出电压分量。

```text
P = Kp e
v = P + I
Ī = Ki e + Kaw(u实际 − v请求)
```

最后一项是回算抗饱和。电流环有解耦前馈，回算时减掉前馈，使反馈修正对应 PI 本身。d/q 电压一起做矢量限幅，不是各自独立截断。电压上限为 Vdc/√3，表示平均逆变器的线性调制范围假设。

当前使用的前馈为：

```text
ud_ff = −ωe Lσ iq + (Lm/Lr)ψ̇r估计
uq_ff =  ωe[Lσ id + (Lm/Lr)ψr估计]
```

启动先缓慢励磁再提高转速；磁链很小时滑差计算有分母保护。这些是工程数值处理，应与理想公式区分。

## 4. 采样与电阻辨识

`Sample` 只包含电压、电流、转速和时间戳。传感器先引入偏置与噪声，再进行量程限制和可选量化；整个样本可延迟若干周期。

EKF 增广状态 `z=[iα,iβ,ψrα,ψrβ,Rr]`，电阻状态的平均变化率取零，过程噪声允许其缓慢改变。它先预测电流，再用测量电流形成创新：

```text
z− = f离散(z, u测量, ω测量)
P− = FPFᵀ + Q
ν = i测量 − Hz−
S = HP−Hᵀ + R
K = P−HᵀS⁻¹
z+ = z− + Kν
P+ = (I−KH)P−(I−KH)ᵀ + KRKᵀ
```

更新阶段没有真实电阻差值。电阻真值只在评价器计算误差。创新小只表示可测信号拟合得较好，并不保证电阻唯一正确。

## 5. 怎么判断模型值得相信

先验证瞬时功率平衡、静止零输入、雅可比，再固定采样周期，仅增加电机积分子步数验证数值收敛。分别测试无噪声、噪声、偏置、ADC、延迟和不同工况。

固定参数、在线补偿、真实参数参考三组必须使用相同工况。分别观察电阻误差、磁链角误差、速度误差和电流；不得只挑最好的一条曲线。真实参数参考也包含有限采样、控制近似等误差，不是所有指标的数学下界。

把图中某个块对应回代码时，先看块的输入时间，再看运算和输出时间。一个样本记录包含“区间开始计算的控制量”和“区间末采到的测量量”，并非所有信号都在同一瞬间产生。传感器延迟会进一步改变测量年龄。

## 6. SVPWM 与实际脉冲电压

从 αβ 指令逆 Clarke 得到三相参考，再注入零序：

```text
u0 = −[max(ua*,ub*,uc*) + min(ua*,ub*,uc*)]/2
dj = 1/2 + (uj*+u0)/Vdc
c(t) = |2 frac(t/TPWM)−1|
Sj(t) = 1[dj ≥ c(t)]
```

这不是普通正弦SPWM：零序注入提高线性母线利用率，在当前线性范围内产生对称七段SVPWM。也可通过扇区与T1/T2/T0理解同一组作用时间。电机无中性线，必须扣除浮动中性点：`vNO=Vdc(Sa+Sb+Sc)/3`，`vaj=Vdc Sa−vNO`，其余两相同理。000和111都对应零电压矢量。

每个桥臂的边沿是`(1−dj)TPWM/2`和`(1+dj)TPWM/2`。求解器在这些时刻分段，再按积分上限细分。即使某个脉冲比用户设定积分上限更窄，也不会因等间隔粗采样漏掉它。积分上限仍决定连续电机方程的数值精度。

高频CSV记录实际门极状态、三相端电压、子步电流及机械角。为表达理想开关跳变，同一时刻可有边沿前/后两条记录；不能把时间戳去重后再当作原始波形。浏览器只请求所选毫秒窗口，控制曲线仍按Ts记录。

辨识器没有获得内部电流/磁链：电压输入是测量前端提供的区间平均端电压，电流和转速是区间末采样。其平均模型近似在高PWM频率、同步采样下表现较好，但低开关频率、采样相位变化、死区等会造成额外偏差，应单独研究。

## 7. 三维模型与物理信号的对应

机械角由`θ̇m=ωm`与机械状态一起按RK4积分，转子、轴和风扇按该角旋转。磁链箭头用`atan2(ψrβ,ψrα)`映射到电机截面；三相绕组亮度随对应相电流变化。定子保持固定。

历史游标选择某条记录时，三维模型恢复该条记录的机械角、磁链与电流。运行时的短暂角度插值只改善画面，不改变仿真数据。高转速仍可能因屏幕刷新出现频闪，不能用视觉倒转判断电机实际转向。

这是集总电路/机械模型的几何展示，不是由三维网格计算出的电磁场。当前外形尺寸为示意，不从修改的J、Ls或Rr自动反演出真实结构。只有极对数改变时，示意绕组分组随之调整。
